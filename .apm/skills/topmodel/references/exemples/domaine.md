# Exemples : domaines et converters

Modèle de test officiel. Index : [`exemples.md`](../exemples.md).

## Domaine avec séquence, et converter

```yaml
domain:
  name: DO_SEQ_ID
  autoGeneratedValue:
    sequenceName: SEQ_{class.sqlName}
    start: 1000
    increment: 50
---
converter:
  from: [DO_ID, DO_ID_2, DO_SEQ_ID]
  to: [DO_LIBELLE]
  java:
    text: "{value}.toString()"
```
