# Syntaxe — fichier `.tmd` et types de documents

Référence de [`SKILL.md`](../../SKILL.md). Les listes de clés sont **fermées** (`additionalProperties: false`) pour l'entête, `class`, `endpoint`, `dataFlow` et les 4 variantes de propriété : une clé non listée fait échouer la validation avec un message illisible (décodage : [`outillage/modgen.md`](../outillage/modgen.md) § Décoder les erreurs). `domain`, `converter`, `decorator` et `annotation` acceptent en plus une clé **par langage** (`csharp:`, `java:`, `ts:`…), de forme elle-même fermée (voir le tableau). Ce que le générateur fait de ces clés, et les pièges : [`regles.md`](../regles.md) ; effets propres à un langage : [`generateurs.md`](../generateurs.md).

## Structure d'un fichier `.tmd`

Un fichier est une suite de documents YAML séparés par `---`. Le **premier** est l'entête du fichier, les suivants sont chacun d'un des 7 types.

```yaml
module: Model # requis
tags: # requis - pilote quels générateurs traitent ce fichier
  - back
uses: # requis pour toute référence à une classe d'un autre fichier
  - Data/Catalogue/Produit
options: # optionnel : { endpoints: { prefix: api/xxx, fileName: Xxx } } (préfixe de route, nom du fichier généré)
---
class: ...
```

| Type de document  | Clés racines                                                                                                                                                                                                                                                                                         | Requis                                   |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------- |
| entête de fichier | `module`, `tags`, `uses`, `options`                                                                                                                                                                                                                                                                  | `module`, `tags`                         |
| `class`           | voir [`classe.md`](classe.md)                                                                                                                                                                                                                                                                        | `name`, `comment`, `properties`          |
| `domain`          | `name`, `label`, `length`, `scale`, `autoGeneratedValue`, `paramLocation`, `defaultValue`, `collection`, `asDomains`, `mediaType`, `annotations`, `excludedAnnotations`, `parameters`, implémentation par langage (`type`, `genericType`, `imports`, `collector`, `values: { template, overrides }`) | `name`                                   |
| `converter`       | `from`, `to`, implémentation par langage (`text`, `imports`)                                                                                                                                                                                                                                         | `from`, `to`                             |
| `decorator`       | `name`, `description`, `target`, `properties`, `decorators`, `annotations`, `propertyAnnotations`, `excludedAnnotations`, `preservePropertyCasing`, `propertySourceOrder`, `parameters`, implémentation par langage (`extends`, `implements`, `imports`)                                             | `name`, `description`                    |
| `endpoint`        | `name`, `method`, `route`, `description`, `params`, `returns`, `tags`, `decorators`, `annotations`, `excludedAnnotations`, `propertyAnnotations`, `customProperties`, `preservePropertyCasing`, `propertySourceOrder`                                                                                | `name`, `method`, `route`, `description` |
| `dataFlow`        | `name`, `target`, `class`, `type`, `sources`, `dependsOn`, `hooks`, `activeProperty`                                                                                                                                                                                                                 | `name`, `target`, `class`, `type`        |
| `annotation`      | `name`, `description`, `target`, `global`, `parameters`, implémentation par langage (**liste** de `{ text, imports, when }`, `text` requis)                                                                                                                                                          | `name`, `description`                    |

Pour une `class` : [`classe.md`](classe.md). Pour les propriétés d'une classe ou d'un endpoint : [`proprietes.md`](proprietes.md). Pour un document `annotation` : [`annotations.md`](annotations.md). Règles propres à un endpoint (emplacement des paramètres, corps, fichiers générés) : [`regles/endpoints.md`](../regles/endpoints.md).
